# 부록

<PartLessons dir="appendix" />

## 부록은 이렇게 쓰세요

부록은 처음부터 끝까지 읽는 곳이 아니라 **필요할 때 찾아보는 곳**입니다. 레슨을 따라 하다가 막히면 아래 순서로 찾아보세요.

| 이럴 때 | 여기를 보세요 |
|---|---|
| 명령이 기억나지 않는다, Windows와 macOS 명령이 헷갈린다 | [명령어 모음](./01-commands) |
| 레슨에 나온 낯선 단어의 뜻을 모르겠다 | [용어 사전](./02-glossary) |
| "왜 안 되지?", "이건 왜 이렇게 하지?" 같은 질문이 생겼다 | [자주 묻는 질문](./03-faq) |
| 더 깊이 공부하거나 최신 정보를 확인하고 싶다 | [참고 자료](./04-resources) |

## 찾아보기 팁

- 화면 위쪽의 **검색**(단축키 `Ctrl+K`, macOS는 `Cmd+K`)으로 용어나 명령을 바로 찾을 수 있습니다. 이 검색은 [왜 VitePress인가](../part2-choices/02-why-vitepress)에서 다룬 내장 로컬 검색입니다.
- 명령어 모음의 명령은 작성 시점(2026-10) Windows 11 PC(Node 24.13.1, npm 11.8.0, Docker 25.0.3)에서 실제로 실행해 확인한 것입니다. macOS/Linux 전용 명령은 표에 따로 표시했습니다.
- 버전·요금·정책처럼 바뀌기 쉬운 내용은 [참고 자료](./04-resources)의 공식 문서에서 다시 확인하세요.
- 문제가 생겼을 때 원인을 찾는 순서는 [문제 해결: 서버가 안 뜰 때](../part6-serve/06-troubleshooting)에 정리되어 있습니다.
