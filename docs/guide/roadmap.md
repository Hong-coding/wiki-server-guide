# 학습 로드맵

이 가이드는 **ts-wiki(TypeScript 마스터 위키)** 하나를 교재로 씁니다. ts-wiki는 `D:\workspace\ts-wiki` 폴더에 있는 실제 프로젝트이고, 지금 이 가이드도 똑같은 구조로 만들어졌습니다. 그래서 가이드를 읽는 동안 "이 화면이 어떻게 만들어졌지?"가 궁금하면, 이 가이드 자체의 소스(`D:\workspace\wiki-server-guide`)를 열어 확인할 수 있습니다.

## 이 가이드로 할 수 있게 되는 것

1. 브라우저에 웹 페이지가 뜨기까지 무슨 일이 일어나는지 설명할 수 있습니다.
2. ts-wiki가 왜 VitePress·Markdown·TypeScript·GitHub Pages·Docker를 골랐는지, 대안과 비교해 말할 수 있습니다.
3. ts-wiki의 모든 파일을 열어 각 줄이 무슨 일을 하는지 읽을 수 있습니다.
4. 빈 폴더에서 같은 수준의 위키를 직접 만들 수 있습니다.
5. 그 위키를 **개발 서버 · Docker(nginx) · GitHub Pages** 세 가지 방법으로 띄우고, 안 뜰 때 원인을 찾을 수 있습니다.
6. 위키를 넘어 일반 웹 서버를 만들고 운영하는 공부를 어떤 순서로 이어 가면 되는지 압니다.

## 전체 흐름

```text
Part 0 시작하기          ─ 무엇을 만드나, 도구 설치
Part 1 웹 서버 기초 개념  ─ 브라우저·서버·HTTP·포트·Node.js·빌드
Part 2 기술 선택의 이유   ─ 왜 VitePress·Markdown·TS·Pages·Docker인가
Part 3 라이브러리 사전    ─ 각 도구가 하는 일과 기본 사용법
Part 4 ts-wiki 해부하기  ─ 실제 파일을 한 줄씩 읽기
Part 5 처음부터 따라 만들기 ─ 빈 폴더에서 나만의 위키 완성
Part 6 서버 띄우기와 배포  ─ dev 서버 · Docker · GitHub Pages · 문제 해결
Part 7 서버 학습 로드맵   ─ Node.js·Express·리버스 프록시·리눅스·운영
부록                     ─ 명령어 모음 · 용어 사전 · FAQ · 참고 자료
```

## 나에게 맞는 시작점

| 지금 나는 | 추천 경로 |
|---|---|
| 서버·터미널이 처음이다 | Part 0부터 순서대로 전부 |
| 웹 개발은 해 봤지만 서버를 띄워 본 적은 없다 | Part 0 → Part 2 → Part 4 → Part 6 → Part 7 |
| 일단 ts-wiki를 켜 보고 싶다 | [5분 만에 바로 띄우기](./quickstart) → Part 6 |
| 똑같은 위키를 하나 더 만들고 싶다 | Part 4 → Part 5 → Part 6 |
| 위키보다 서버 자체를 공부하고 싶다 | Part 1 → Part 3의 nginx·Docker → Part 7 |

## 공부하는 방법

- **눈으로만 읽지 말고 명령을 직접 실행합니다.** 서버 공부는 "켜 보고, 꺼 보고, 일부러 망가뜨려 보는" 것이 전부라고 해도 과언이 아닙니다.
- **실습 레슨에는 "확인 방법"이 있습니다.** 화면에 무엇이 보여야 성공인지 적어 두었으니, 결과가 다르면 그 레슨의 "자주 하는 실수"와 [문제 해결](../part6-serve/06-troubleshooting)을 봅니다.
- **실습은 ts-wiki를 직접 고치지 말고 복사본이나 새 폴더에서 합니다.** 원본이 망가지면 다른 공부를 이어 갈 수 없습니다.
- 마친 레슨은 [진도 체크리스트](./checklist)에 표시합니다.
